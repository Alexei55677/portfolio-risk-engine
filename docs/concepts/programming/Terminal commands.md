

| Command           | What it does                                                                                                                                                                                                                                                                                                                                                        | Example |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| `pwd`             | Prints working directory                                                                                                                                                                                                                                                                                                                                            |         |
| `ls`              | Lists the files and folders in the current directory, skipping hidden ones                                                                                                                                                                                                                                                                                          |         |
| `ls -Force`       | Lists the files and folders in the current directory, including hidden ones                                                                                                                                                                                                                                                                                         |         |
| `cd <path>`       | Changes to the folder at the given path, either absolute (full address from the drive) or relative (directions from where you are)                                                                                                                                                                                                                                  |         |
| `cd ..`           | Moves up to the parent folder; `..` can be chained or combined with other folder names                                                                                                                                                                                                                                                                              |         |
| `mkdir <name>`    | Makes a new folder (directory); creates any missing parent folders too                                                                                                                                                                                                                                                                                              |         |
| `New-Item <name>` | Makes a new empty file                                                                                                                                                                                                                                                                                                                                              |         |
| `Remove-Item`     | deletes from your **disk**, not memory, and the important part: **it skips the Recycle Bin.** The file is gone permanently, with no undo. The one safety net is Git: if the file was committed, `git restore <file>` brings back the last committed version. An untracked file like `scratch.txt` has no backup at all. So double-check the name before running it. |         |
| `notepad <file>`  | opens the file in Notepad. If the file doesn’t exist yet, Notepad asks whether to create it.                                                                                                                                                                                                                                                                        |         |
